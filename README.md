# work-card

> 매주 반복하는 업무 하나를 AI가 읽고 실행할 수 있는 카드로 만들고, 그 카드에서 바로 쓸 수 있는 스킬을 생성한다.

Claude Code 스킬 하나. 설명을 듣는 게 아니라 **자기 업무 하나가 실제로 돌아가는 것**까지 간다.

## 설치

```bash
npx skills add ai-native-camp/work-card --agent claude-code --yes
```

Claude Code 대화창에서:

```
/work-card
```

## 필요한 것

| 항목 | 확인 |
|---|---|
| Claude 구독 (Pro / Max / Teams / Enterprise) | 로그인 시 확인됨 |
| Claude Code | 터미널에 `claude` → 인사하면 성공 |
| Node.js | 터미널에 `npx -v` → 버전 나오면 OK |

Claude Code가 없다면 [claude.ai](https://claude.ai) 대화창에 "Claude Code 설치하는 방법 알려줘"라고 물어보면 환경에 맞게 안내해준다.

**터미널 여는 법** — Mac: `⌘ + Space` → "터미널" / Windows: 시작 → "PowerShell"

## 무엇을 하는가

여섯 가지를 하나씩 묻는다.

1. 얼마나 자주 하고 몇 분 걸리나
2. 뭘 보면 시작하나
3. 뭘 열고 어디서 가져오나
4. 순서가 어떻게 되나
5. **어디가 내가 정해야 하는 지점인가**
6. 뭘 보면 끝났고 누구한테 가나

다섯 번째가 핵심이다. 판단이 들어가는 지점이 그 사람이 대체 불가능한 곳이고, 나머지는 넘길 수 있다. 이 구분이 서면 자동화할 것과 안 할 것이 저절로 갈린다.

## 결과물

```
work-cards/2026-07-27-주간리포트.md      ← 업무 카드
.claude/skills/주간리포트/SKILL.md        ← 바로 쓸 수 있는 스킬
```

두 번째가 목적지다. 새 대화에서 `/주간리포트`를 치면 방금 말한 그 일이 돌아간다.

## 설계 원칙

- **질문은 하나씩** — 한꺼번에 물으면 요약해서 답하고, 요약된 답에는 실제로 어떻게 일하는지가 빠진다
- **대신 답하지 않는다** — 막혀도 예시를 던져 채우지 않는다. "지난주에 하셨죠? 그때 뭐부터 하셨어요"로 되묻는다
- **용어를 먼저 쓰지 않는다** — 워크플로우·트리거·인풋 같은 말 없이 묻고, 카드에 옮길 때 정리한다
- **모르는 칸은 비워둔다** — 억지로 채운 칸이 빈 칸보다 나쁘다. 빈 칸이 다음에 알아낼 것을 알려준다
