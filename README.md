# work-card

> Medit 전략마케팅팀 AI 밀착 교육 1회차 실습 — 혼자 진행하는 파트.

세션에서 설치·로그인·`/init`까지 하고, 실습은 각자 진행한다. 이 스킬이 그 실습을 끝까지 끌고 간다.

## 설치

세션에서 만든 작업 폴더(`~/dev/<이름>`)에서:

```bash
npx skills add delta-society/work-card --agent claude-code --yes
```

## 실행

```
/day1-start
```

터미널이 아니라 **Claude 대화창 안에서** 친다.

## 블록

| 블록 | 하는 것 | 시간 |
|---|---|---|
| 1 | **인수인계서 일곱 줄** (`CLAUDE.md` 채우기) | 15분 |
| 2 | **내 업무로 만들고 스킬화** ← 핵심 | 30분 |
| 3 | 슬랙에 올릴 결산 | 5분 |
| 상시 | 막혔을 때 | — |
| 선택 | 맥락 연동 (MCP) | — |

**다른 창으로 옮기지 않는다.** 대화가 곧 실습이다.

## 끝나면 손에 남는 것

```
CLAUDE.md                              ← 일곱 줄이 채워진 인수인계서
work-cards/<날짜>-day1.md              ← 결산 (슬랙 복사용)
.claude/skills/<내업무>/SKILL.md        ← 내 작업에서 나온 스킬
```

## 설계 원칙

**교보재가 아니다.** 남이 만든 스킬을 실행해보는 게 아니라, 본인 업무에서 산출물과 스킬이 나와야 끝난다. 예시 업무로 진행하거나 사용자 대신 내용을 채우지 않는다.

**대화가 곧 실습이다.** "이렇게 해보세요" 하고 물러나지 않는다. 질문 하나 → 답 받기 → 다음 질문으로 여기서 같이 만든다.

**질문은 한 번에 하나.** 일곱 줄을 나열하고 채워보라고 하면 아무것도 안 나온다. 한 줄 묻고, 답을 되읽어주고, 다음 줄로 간다.

**막히면 되묻되 답을 주지 않는다.** 되묻기는 한 번, "지난주에 하셨죠?"처럼 실제 사례를 떠올리게 하는 방식으로. 그래도 안 나오면 `(아직 모름)`으로 둔다. 억지로 채운 칸이 빈 칸보다 나쁘다.

**완성이 목적이 아니다.** 만들다 막힌 지점이 다음 세션의 재료다. 막힘은 그때그때 결산 파일에 적어두고, Block 3에서 슬랙에 그대로 붙여넣을 형태로 정리해준다.

**막힘은 성격을 가른다.** 요청이 애매해서 막힌 것(다시 물으면 풀림)과 권한·계정·회사 제한으로 막힌 것(개인이 못 넘음)을 구분한다. 후자는 정확히 적혀 있어야 조직이 다룰 수 있다.

## 특히 Block 1의 두 질문

**5번 — 좋은 결과의 기준.** 직접 물으면 대부분 막히므로 반례부터 묻는다: *"예전에 '이건 좀 아닌데' 싶었던 적 있으세요?"* 답이 나오면 뒤집어 정리해준다.

**6번 — 추측하면 안 되는 것.** 가장 중요한 줄이다. AI가 그럴듯한 오답을 내놓는 것을 막는 자리다.

## 필요한 것

| 항목 | 확인 |
|---|---|
| Claude 구독 | 세션에서 로그인 완료 |
| Claude Code | 터미널에 `claude` |
| 작업 폴더 | 세션에서 만든 `~/dev/<이름>` |

**설치한 폴더에서 실행해야 한다.** 다른 폴더면 `/day1-start`가 안 보인다. 스킬이 시작할 때 `CLAUDE.md` 존재로 폴더를 확인하고, 없으면 이동 방법을 안내한다.
