# work-card

> Medit 전략마케팅팀 AI 밀착 교육 1회차 실습 — 혼자 진행하는 파트.

세션에서 기초 세팅까지 하고, 실습은 각자 진행한다. 이 스킬이 그 실습을 끝까지 끌고 간다.

## 설치

```bash
npx skills add delta-society/work-card --agent claude-code --yes
```

## 실행

```
/day1-start
```

터미널이 아니라 **Claude 대화창 안에서** 친다.

## 블록

| 블록 | 하는 것 | 시간 |
|---|---|---|
| 1 | 추측과 질문의 차이 | 5분 |
| 2 | 명령어를 외우지 않아도 되는 이유 | 5분 |
| 3 | **인수인계서 일곱 줄** (`CLAUDE.md` 채우기) | 15분 |
| 4 | **내 업무로 만들고 스킬화** ← 핵심 | 30분 |
| 5 | 슬랙에 올릴 결산 만들기 | 5분 |
| 6 | 맥락 연동 — MCP (선택) | — |

시간이 없으면 **3번과 4번만** 해도 된다.

블록마다 2턴으로 나뉜다. 설명 + "직접 해보세요" → ⛔멈춤 → "완료" 입력 → 확인 질문.

## 끝나면 손에 남는 것

```
CLAUDE.md                              ← 일곱 줄이 채워진 인수인계서
work-cards/<날짜>-day1.md              ← 결산 (슬랙 복사용)
.claude/skills/<내업무>/SKILL.md        ← 내 작업에서 나온 스킬
```

## 설계 원칙

**교보재가 아니다.** 남이 만든 스킬을 실행해보는 게 아니라, **본인 업무에서 산출물과 스킬이 나와야** 끝난다. 예시 업무로 진행하거나 사용자 대신 내용을 채우지 않는다.

**완성이 목적이 아니다.** 만들다 막힌 지점이 다음 세션의 재료다. 그래서 진행 중 막힘을 상시 기록하고, Block 5에서 슬랙에 그대로 붙여넣을 수 있는 형태로 정리해준다.

**막힘은 성격을 가른다.** 요청이 애매해서 막힌 것(다시 물으면 풀림)과 권한·계정·회사 제한으로 막힌 것(개인이 못 넘음)을 구분해 기록한다. 후자는 정확히 적혀 있어야 조직이 다룰 수 있다.

**대신 답하지 않는다.** 막혀도 예시를 던져 채우지 않는다. 되묻기는 한 번, "지난주에 하셨죠?"처럼 실제 사례를 떠올리게 하는 방식으로.

**모르는 칸은 비워둔다.** 억지로 채운 칸이 빈 칸보다 나쁘다.

## 막혔을 때

진행 중 아무 때나 "막혔어"라고 하면 `block-stuck.md`가 열린다. 한 번 풀어보고, 안 되면 성격을 갈라 슬랙에 올릴 문구를 만들어준다. 개인이 못 넘는 벽이면 붙잡지 않고 기록만 하고 넘어간다.

## 필요한 것

| 항목 | 확인 |
|---|---|
| Claude 구독 | 세션에서 로그인 완료 |
| Claude Code | 터미널에 `claude` |
| 작업 폴더 | 세션에서 만든 `~/dev/<이름>` |

**설치한 폴더에서 실행해야 한다.** 다른 폴더에서 `claude`를 열면 `/day1-start`가 안 보인다.
