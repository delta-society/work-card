# work-card

> Medit 전략마케팅팀 AI 밀착 교육용 Claude Code 스킬.

발표 자료 Session 1의 실습 파트를 그대로 실행한다. **현재 1회차(`day1-start`)만 있다** — 2·3회차는 1회차 세 줄 결산을 받은 뒤에 만든다.

## 설치

```bash
npx skills add delta-society/work-card --agent claude-code --yes
```

## 실행

```
/day1-start
```

터미널이 아니라 **Claude 대화창 안에서** 친다.

## 블록 구성

| 블록 | 하는 것 | 자료 |
|---|---|---|
| 0 | 구동 3줄 · 첫 대화 · `/config` Explanatory | 20~21장 |
| 1 | 추측과 질문의 차이 — 같은 요청 두 번 | 22장 |
| 2 | 명령어를 외우지 않아도 되는 이유 · `!` | 23장 |
| 3 | **내 인수인계서 일곱 줄** (`CLAUDE.md`) | 24장 |
| 4 | **반복 업무 하나를 레시피로** (Skill) | 25장 |
| 5 | 세 줄 결산 + 예측 회수 | 26~27장 |
| 6 | **맥락 연동 — MCP** · 선택 | 14장 |

블록마다 2턴으로 나뉜다. 설명 + "직접 해보세요" → ⛔멈춤 → 사용자가 "완료" → 확인 질문.

## 완료 기준

**Block 5까지 하면 완료다.** 레시피가 완성되지 않아도 된다 — 자료 25장: "어디서 막히는지 확인하는 것까지가 오늘 몫이고, 막힌 지점이 수요일 세션의 재료다."

**Block 6은 선택이다.** 시간이 남을 때만 연다.

## 컨텍스트 연동 (Block 6)

Block 3·4에서 내가 아는 것을 **말로 옮겨** AI에게 줬다면, Block 6은 이미 어딘가에 있는 자료를 **도구째 연결**한다. 매번 복사-붙여넣기 하면 5분이면 지쳐서 안 하게 되기 때문이다(자료 10장).

```
claude mcp list          # 지금 연결된 것 보기
claude mcp add ...       # 연결
claude mcp get <이름>     # 상세 확인
```

오늘은 **무엇을 연결하고 싶은지 목록이 나오는 것까지**가 성과다. 회사 계정·사내 시스템 실제 연결은 하지 않는다 — 연결 범위는 회사가 허용한 만큼이고, 무엇을 연결할지는 오늘 결정하지 않는다(자료 14장).

승인이 필요한 항목은 세 줄 결산 3번에 들어가고, 그게 다음 회차 재료가 된다.

## 필요한 것

| 항목 | 확인 |
|---|---|
| Claude 구독 (Pro / Max / Teams / Enterprise) | 로그인 시 확인됨 |
| Claude Code | 터미널에 `claude` → 인사하면 성공 |
| Node.js | 터미널에 `npx -v` → 버전 나오면 OK |

Claude Code가 없다면 [claude.ai](https://claude.ai) 대화창에 "Claude Code 설치하는 방법 알려줘"라고 물어보면 환경에 맞게 안내해준다.

**터미널 여는 법** — Mac: `⌘ + Space` → "터미널" / Windows: 시작 → "PowerShell"

## 결과물

```
CLAUDE.md                              ← 내 인수인계서 일곱 줄
work-cards/<날짜>-<업무>.md             ← 세 줄 결산 + 막힌 지점
.claude/skills/<업무>/SKILL.md          ← 내 레시피 (미완성도 괜찮음)
```

## 설계 원칙

- **STOP PROTOCOL** — 블록마다 2턴. 한 턴에 몰아서 하면 실습이 사라진다
- **AskUserQuestion** — 선택지를 주고 묻는다. 열린 질문만 던지면 "글쎄요"가 나온다
- **한 번에 한 파일** — references를 미리 여러 개 읽으면 블록이 뭉개진다
- **대신 답하지 않는다** — 막혀도 예시를 던져 채우지 않는다. 되묻기는 한 번, "지난주에 하셨죠?"처럼 실제 사례를 떠올리게 하는 방식
- **용어를 먼저 쓰지 않는다** — 워크플로우·트리거 같은 말 없이 묻고, 정리할 때 붙인다
- **모르는 칸은 비워둔다** — 억지로 채운 칸이 빈 칸보다 나쁘다
- **자료에 없는 걸 만들지 않는다** — 발표 자료의 실습 파트를 실행하는 스킬이지, 별도 커리큘럼이 아니다
