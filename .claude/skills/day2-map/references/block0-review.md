# Block 0: 지난주 돌아보기

## EXPLAIN

지난 회차 이후 며칠이 지났다. 그 사이가 세션 두 시간보다 중요하다.

무엇이 잘 됐는지보다 **어디서 막혔는지**가 오늘의 재료다.

## EXECUTE

두 가지를 해본다.

**1. 지난 흔적 떠올리기**

지난주에 Claude에게 뭘 시켜봤는지, 잘 된 것과 안 된 것을 각각 하나씩 떠올린다.

**2. 안 된 것 다시 시켜보기**

안 됐던 것을 지금 한 번 더 시켜본다. 이번엔 이렇게 붙여서.

```
[원래 요청]. 모호한 부분은 AskUserQuestion으로 질문해서 명확하게 만들어
```
