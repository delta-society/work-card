# Block 1: 순서 펼치기

## EXPLAIN

이제 카드의 빈칸을 채운다. 첫 번째는 **순서**다.

"어떻게 하세요"라고 물으면 대부분 두세 단계로 뭉뚱그린다. 실제로는 훨씬 많다. 뭉뚱그린 부분에 넘길 수 있는 일이 숨어 있다.

## EXECUTE

```
그 일 하실 때, 그다음엔 뭘 하세요? 순서대로 얘기해주세요.
```

열린 질문으로 묻는다. 사용자가 말하는 대로 받아적는다. → ⛔ STOP

**되묻기는 한 번만.** 두세 단계에서 멈추면:

```
지난주에 이거 하셨죠? 그때 뭐부터 하셨어요?
```

추상적으로 물으면 추상적으로 답한다. **지난번 실제 사례 하나**를 떠올리게 하는 편이 항상 빠르다.

받은 내용을 번호 목록으로 정리해서 보여준다. 사용자 표현을 살린다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "정리한 순서가 실제와 맞나요?",
    "header": "순서 확인",
    "options": [
      {"label": "맞아요", "description": "다음으로"},
      {"label": "빠진 단계가 있어요", "description": "추가하겠습니다"},
      {"label": "순서가 다릅니다", "description": "고치겠습니다"},
      {"label": "매번 달라요", "description": "고정된 순서가 없음"}
    ],
    "multiSelect": false
  }]
})
```

**4번(매번 달라요)이 중요한 답이다.** 그때는 이렇게 되묻는다:

> "그럼 제일 흔한 경우 하나만 잡아볼까요? 나머지는 그 변형으로 두면 됩니다."

⚠ 이 번호 목록은 **다음 블록의 선택지가 된다.** 정확히 확정하고 넘어간다.
