# Block 2: 판단 지점 찾기 — 오늘의 핵심

> 여기가 이 프로그램 전체의 핵심이다.
> 판단이 들어가는 지점 = 그 사람이 대체 불가능한 곳.
> 나머지 = 넘길 수 있는 것.
> 이 선이 그어지면 무엇을 자동화하고 무엇을 남길지가 저절로 갈린다.

## EXPLAIN

방금 펼친 순서를 다시 본다.

그중에는 **누가 해도 같은 결과가 나오는 단계**가 있고, **내가 판단해야만 하는 단계**가 있다. 이 둘은 성격이 완전히 다르다.

앞쪽은 넘길 수 있다. 뒤쪽은 못 넘긴다 — 못 넘기는 게 문제가 아니라, **그게 내가 이 일에 남아 있는 이유**다.

AI에게 일을 맡긴다는 건 전부를 넘기는 게 아니라 이 선을 긋는 일이다.

## EXECUTE

**Block 1에서 받은 단계들을 그대로 선택지로 만든다.** 미리 준비된 옵션이 아니라, 사용자 본인의 순서를 되돌려주는 것이다.

```json
AskUserQuestion({
  "questions": [{
    "question": "방금 말씀하신 단계 중에, '이건 내가 정해야 한다' 싶은 데가 어디예요?",
    "header": "판단 지점",
    "options": [
      {"label": "<Block1의 1단계>", "description": "<그 단계 설명>"},
      {"label": "<Block1의 2단계>", "description": "<그 단계 설명>"},
      {"label": "<Block1의 3단계>", "description": "<그 단계 설명>"},
      {"label": "<Block1의 4단계>", "description": "<그 단계 설명>"}
    ],
    "multiSelect": true
  }]
})
```

`multiSelect: true` — 여러 곳일 수 있다. 단계가 5개를 넘으면 4개로 묶어서 제시한다.

→ ⛔ STOP

**되묻기 — 이 블록만은 반드시 한 번 판다.**

```
그때 뭘 보고 정하세요? 기준 같은 게 있나요?
```

기준이 나오면 그게 3회차에 스킬로 들어갈 규칙이다.
**"그냥 감으로"라고 하면 그것도 그대로 적는다** — 감으로 하는 판단이 바로 못 넘기는 판단이고, 그게 이 사람이 남아야 하는 이유다.

## CHECK

먼저 선이 그어진 것을 **소리 내어 짚어준다.**

```
그럼 이렇게 나뉘네요.

  넘길 수 있는 것: <선택 안 된 단계들>
  내가 해야 하는 것: <선택된 단계들>
```

그다음 확인한다.

```json
AskUserQuestion({
  "questions": [{
    "question": "이렇게 나눠놓고 보니 어떠세요?",
    "header": "확인",
    "options": [
      {"label": "맞다 — 저 부분은 내가 봐야 한다", "description": "구분이 맞음"},
      {"label": "생각보다 넘길 게 많다", "description": "예상 밖"},
      {"label": "판단 지점을 더 잘게 나눠야 할 것 같다", "description": "한 단계 안에 섞여 있음"},
      {"label": "다시 고르고 싶다", "description": "선택 변경"}
    ],
    "multiSelect": false
  }]
})
```

3번을 고르면 해당 단계를 둘로 쪼개서 다시 묻는다. **한 단계 안에 기계적인 부분과 판단이 섞여 있는 경우가 실제로 흔하고, 쪼개는 순간 넘길 수 있는 범위가 늘어난다.**
