# Block 3: 완료·수신자 + 카드 완성

## EXPLAIN

마지막 칸이다. **뭘 보면 끝났고, 그게 누구한테 가는가.**

끝나는 조건이 흐릿하면 AI에게 맡길 수 없다. 어디까지 하고 멈춰야 할지 모르기 때문이다.

## EXECUTE

```json
AskUserQuestion({
  "questions": [{
    "question": "뭘 보면 이 일이 끝났다고 하세요?",
    "header": "완료 조건",
    "options": [
      {"label": "문서·파일이 나오면", "description": "산출물이 생김"},
      {"label": "누구한테 보내면", "description": "전달이 끝"},
      {"label": "어딘가에 올리면", "description": "게시가 끝"},
      {"label": "확인 받으면", "description": "승인이 끝"}
    ],
    "multiSelect": false
  }]
})
```

이어서: **"그거 누구한테 가요?"** → ⛔ STOP

"아무도 안 봐요"라고 하면 한 번 되묻는다: *"그럼 이거 안 하면 누가 아쉬워하세요?"*
아무도 없으면 그것도 발견이다 — **아무도 안 보는 일에 매주 시간을 쓰고 있었다는 것.** 카드에 그대로 적는다.

### 카드 완성

1회차 카드 파일을 열어 나머지 칸을 채우고 아래 세 절을 덧붙인다.

```markdown
## 넘길 수 있는 것
<Block 2에서 선택되지 않은 단계들>

## 내가 해야 하는 것
<Block 2 판단 지점 + 기준>

## 아직 모르는 것
<(아직 모름)으로 남긴 칸들>
```

**모르는 칸은 비워둔다.** `(아직 모름)`으로 남긴다. 억지로 채운 칸이 빈 칸보다 나쁘다 — 빈 칸이 다음에 무엇을 알아내야 하는지 알려준다.

저장하고 카드 전문을 보여준다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "카드가 다 찼습니다. 이대로 3회차에 스킬로 만들면 될까요?",
    "header": "카드 확정",
    "options": [
      {"label": "좋아요", "description": "이대로 진행"},
      {"label": "고칠 데가 있어요", "description": "어디인지 알려주세요"},
      {"label": "빈 칸이 신경 쓰여요", "description": "채우고 갈지 논의"}
    ],
    "multiSelect": false
  }]
})
```

3번을 고르면 이렇게 답한다:

> "빈 칸이 있어도 스킬은 만들어집니다. 오히려 돌려보면 그 칸에 뭐가 들어가야 하는지가 드러납니다."

마무리 안내:

```
오늘은 여기까지입니다.

카드 여섯 칸이 다 찼고, 넘길 것과 남길 것이 갈렸습니다.
3회차에서 이 카드가 실제로 돌아가는 스킬이 됩니다.

[다음까지 해보실 것]
'넘길 수 있는 것'에 있는 단계 중 하나만 Claude에게 시켜보세요.
되든 안 되든 채널에 남겨주세요. 안 되는 게 더 중요한 재료입니다.
```
