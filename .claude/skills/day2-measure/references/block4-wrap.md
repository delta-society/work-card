# Block 4: 세 줄로 남기기

> 금요일 세션 설계의 재료다.

## EXPLAIN

오늘도 세 줄로 남긴다. 항목이 1회차와 다르다.

```
1. 내가 정한 기준은            — 한 줄로. 오늘 정한 판정 기준.
2. AI에게 못 넘긴 자리는        — 한 줄로. 사람이 봐야만 하는 곳.
3. 아직 안 풀린 것은           — 한 줄로. 이 줄이 금요일 인계 목록이 된다.
```

## EXECUTE

Day 1 카드 파일에 이어서 덧붙인다.

```markdown
## Day 2 — 세 줄
1. 내가 정한 기준:
2. AI에게 못 넘긴 자리:
3. 아직 안 풀린 것:

## 판정 기준 (상세)
<Block 2에서 정리한 것>

## 개인이 못 넘는 벽
<Block 1에서 3번(권한·데이터)으로 분류된 것들>

## 레시피 상태
- 스킬: `.claude/skills/<이름>/SKILL.md`
- 기준 반영: <됨 / 일부 / 미반영>
- 돌려봄: <됨 / 안 됨>
```

저장하고 경로를 보여준다.
