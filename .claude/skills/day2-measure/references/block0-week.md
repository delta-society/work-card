# Block 0: 지난 이틀

## EXPLAIN

1회차 끝에 두 가지를 부탁했다 — 두 번 실행해보기, 내일 아침에 한 번 열어보기.

했든 안 했든 상관없다. **안 열어봤으면 왜 안 열게 됐는지가 오늘의 재료다.**

## EXECUTE

Day 1 카드의 세 줄을 소리 내어 읽어준다. 그다음 물어본다.

```
저 세 줄 쓰신 뒤로, 실제로 한 번이라도 열어보셨어요?
```

열어봤으면 그때 뭘 시켜봤는지, 안 열었으면 왜 그랬는지 그냥 편하게 답하면 된다.
