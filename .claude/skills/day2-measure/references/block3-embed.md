# Block 3: 기준을 레시피에 심기

## EXPLAIN

기준을 머릿속에만 두면 매번 다시 설명해야 한다. 레시피에 심으면 다음부터 자동으로 적용된다.

심을 때 두 가지로 나눈다.

- **AI가 판정할 수 있는 것** → 규칙으로 적는다. AI가 알아서 확인한다
- **사람이 봐야만 하는 것** → "여기서는 반드시 물어본다"로 적는다. AI가 멈추고 물어본다

두 번째가 없으면 AI가 사람 판단까지 대신해버린다.

## EXECUTE

1회차에 만든 Skill이 있으면 거기에 심고, 없으면 지금 만든다.

**있는 경우** — Claude에게 말로 시킨다.

```
방금 정한 기준을 /<스킬이름> 에 넣어줘.
사람이 봐야 하는 부분은 나한테 물어보고 넘어가게 해줘.
```

**없는 경우** — 1회차 Block 4의 세 단계를 지금 한다.

```
1. 그 일을 어떻게 하는지 말로 설명
2. "내 설명에서 빠진 게 뭐야?" 되묻게 하기
3. "지금까지 내용을 Skill로 만들어줘"
```

만들 때 방금 정한 기준을 함께 넣는다.

**그리고 한 번 돌려본다.**

```
/<스킬이름>
```

기준이 실제로 적용되는지, 사람이 봐야 하는 자리에서 실제로 멈추고 물어보는지 확인한다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "돌려보니 어땠나요?",
    "header": "실행 확인",
    "options": [
      {"label": "기준대로 나왔다", "description": "적용됨"},
      {"label": "물어봐야 할 데서 안 물어봤다", "description": "고쳐야 함"},
      {"label": "안 물어도 될 걸 물었다", "description": "너무 자주 멈춤"},
      {"label": "아직 못 돌려봤다", "description": "괜찮습니다"}
    ],
    "multiSelect": true
  }]
})
```

2·3번이면 **말로 고친다.** 파일을 열 필요 없다.

- 2번 → `<그 단계>에서는 나한테 물어보고 진행하게 해줘`
- 3번 → `<그 단계>는 물어보지 말고 그냥 진행해`

고치고 한 번 더 돌려본다. 이렇게 짚어준다:

> "지금 하신 게 앞으로 계속 하실 일입니다. 쓰다가 걸리면 말로 고치고, 또 쓰고. 그렇게 내 일에 맞아 들어갑니다."
