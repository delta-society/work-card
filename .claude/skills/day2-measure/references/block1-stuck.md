# Block 1: 안 풀린 것 하나

## EXPLAIN

1회차 세 줄의 3번 — "아직 안 풀린 것". 오늘은 그걸 하나 잡고 시작한다.

푸는 게 목적이 아니다. **왜 안 풀렸는지 성격을 가르는 게** 목적이다. 안 풀리는 이유는 대개 셋 중 하나다.

- 방법을 몰라서 — 물어보면 풀린다
- **기준이 없어서** — 뭘 맞다고 할지 안 정해져서 AI가 아무거나 내놓는다
- 권한·데이터가 없어서 — 개인이 못 넘는다

두 번째가 오늘의 본론이다.

## EXECUTE

Day 1 카드의 3번 줄을 그대로 읽어주고 시작한다.

```
저 안 풀린 것, 지금 한 번 다시 시켜보시겠어요?
```

이번엔 되묻게 붙여서 시킨다.

```
[원래 요청]. 모호한 부분은 나한테 질문해서 명확하게 만들어
```

AI가 되묻는 질문들을 잘 본다. **그 질문에 답이 막히는 지점이 곧 기준이 없는 자리다.**

## CHECK

2번이면 바로 다음 블록으로 간다.
3번이면 **반드시 무엇이 막혔는지 구체적으로 적어둔다** — 3회차 인계 목록에 그대로 올라간다.
4번이면 AI가 되물었던 질문 중 답이 막힌 걸 짚어주고 2번으로 유도한다.
