# Block 2: 좋은 결과의 기준 — 오늘의 핵심

> 인수인계서 5번을 제대로 채우는 블록이다.
> 1회차에서는 한 줄로 적고 넘어갔다. 오늘은 여기에 시간을 다 쓴다.

## EXPLAIN

AI에게 일을 시킬 때 가장 자주 빠지는 것이 **판정 기준**이다.

"잘 해줘"는 기준이 아니다. AI는 무엇이 잘한 것인지 모르고, 그래서 그럴듯한 걸 내놓는다. 시작할 때 걸어둔 예측 ①(그럴듯한 오답)의 뿌리가 여기다.

기준을 정한다는 건 어려운 일이 아니다. **이미 머릿속에 있는 걸 꺼내는 것**이다. 지금까지 그 일을 해오면서 "이건 아니지"라고 판단해온 적이 있다면, 그때 쓴 잣대가 기준이다.

## EXECUTE

세 가지를 순서대로 묻는다. **한 번에 하나씩.**

### 1. 반례부터

기준을 직접 물으면 대부분 막힌다. 반례가 훨씬 쉽다.

```
그 업무 결과물 중에, 예전에 "이건 아닌데" 싶었던 적 있으세요? 뭐가 문제였어요?
```

→ ⛔ STOP. 답을 받는다.

**되묻기는 한 번만**: *"그때 구체적으로 뭘 보고 아니라고 판단하셨어요?"*

### 2. 통과선

```
반대로, 어떤 게 갖춰지면 "이건 나가도 되겠다" 하세요?
```

→ ⛔ STOP.

### 3. 우선순위

```json
AskUserQuestion({
  "questions": [{
    "question": "지금 나온 것들 중에 하나만 못 지킨다면, 뭐가 제일 치명적인가요?",
    "header": "우선순위",
    "options": [
      {"label": "<1·2에서 나온 항목 A>", "description": "<설명>"},
      {"label": "<항목 B>", "description": "<설명>"},
      {"label": "<항목 C>", "description": "<설명>"},
      {"label": "<항목 D>", "description": "<설명>"}
    ],
    "multiSelect": false
  }]
})
```

선택지는 미리 정하지 않는다. **1·2단계에서 사용자가 말한 것을 그대로 되돌려준다.**

### 진행 규칙

- **대신 답하지 않는다.** "보통 이런 기준을 쓰시죠"라고 예시를 던지지 않는다
- "그냥 감으로"라고 하면 그대로 적는다 — **감으로 하는 판정이 바로 못 넘기는 판정**이고, 그게 이 사람이 남아야 하는 이유다
- 용어를 먼저 쓰지 않는다. `판정 기준`, `수용 조건` 같은 말 없이 묻고 정리할 때 붙인다

## CHECK

정리한 기준을 보여주고 묻는다.

```json
AskUserQuestion({
  "questions": [{
    "question": "이렇게 적어놓고 보니 어떠세요?",
    "header": "기준 확인",
    "options": [
      {"label": "맞다 — 이게 내 기준이다", "description": "확정"},
      {"label": "적고 보니 빠진 게 보인다", "description": "추가하겠습니다"},
      {"label": "이건 사람이 봐야만 판단된다", "description": "AI에게 못 넘기는 자리"},
      {"label": "생각보다 명확했다", "description": "이미 알고 있었음"}
    ],
    "multiSelect": true
  }]
})
```

**3번이 중요한 답이다.** 그때는 이렇게 짚는다:

> "그 부분은 AI가 정하면 안 되는 자리입니다. 레시피에 '여기서는 반드시 물어본다'로 심어두면 됩니다."
