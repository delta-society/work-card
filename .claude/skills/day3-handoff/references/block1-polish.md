# Block 1: 산출물을 쓸 수 있는 상태로

## EXPLAIN

오늘은 연습이 아니라 **실제 업무 건**으로 돌린다.

지난주 자료든 이번 주 건이든, 진짜 자료를 넣고 진짜 결과를 받는다. 그리고 그 결과를 2회차에 정한 기준으로 판정한다.

여기서 통과하면 이 레시피는 쓸 수 있는 물건이 된 것이다.

## EXECUTE

**1. 실제 건으로 돌린다**

```
/<스킬이름>
```

진짜 자료를 넣는다. 없으면 지난달 것이라도 쓴다.

**2. 나온 결과를 2회차 기준으로 판정한다**

Day 2 카드에 적힌 판정 기준을 하나씩 대본다. 사람이 봐야 하는 자리에서 실제로 물어봤는지도 확인한다.

**3. 어긋난 데를 말로 고친다**

```
<어긋난 부분>을 이렇게 바꿔줘
```

파일을 열 필요 없다. 고치고 한 번 더 돌린다.

### 진행 규칙

- **결과가 완벽할 필요 없다.** 기준의 몇 할을 만족하는지 보는 게 목적이다
- 사용자가 "이 정도면 됐다"고 하면 거기서 멈춘다. 완벽주의를 밀어붙이지 않는다
- 고치는 횟수 제한은 없다 — **고치는 경험 자체가 학습**이다
