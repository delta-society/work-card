# Block 4: 3회 돌아보기

## EXPLAIN

세 번이 끝났다. 손에 남은 것을 확인하고 마무리한다.

## EXECUTE

3회 전체를 짚어준다.

```
3회 동안 이렇게 왔습니다.

  1회차 — 켜고, 인수인계서를 쓰고, 반복 업무 하나를 레시피로 만들려다 막혔다
  2회차 — 무엇을 좋은 결과로 볼지 정하고, 그 기준을 레시피에 심었다
  3회차 — 실제 업무 건으로 돌리고, 혼자 못 푼 것을 인계 가능한 형태로 남겼다

지금 남은 것:
  · CLAUDE.md — 내 인수인계서
  · /<스킬이름> — 실제로 쓸 수 있는 레시피
  · 인계 목록 — 조직이 다뤄야 할 것
```

카드 파일에 마지막 절을 덧붙인다.

```markdown
## Day 3 — 마무리

### 최종 산출물
- CLAUDE.md: <경로>
- 스킬: `.claude/skills/<이름>/SKILL.md`
- 실제 업무 적용: <됨 / 부분 / 못 함 + 이유>

### 인계 목록
| 항목 | 성격 | 구체적으로 어디서 막히나 |
|---|---|---|
| | 권한/데이터/협조 | |

### 학습으로 풀 수 있는 것
<본인이 계속 해볼 것>
```

저장하고 경로를 보여준다.
