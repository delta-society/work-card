# Block 3: 혼자 못 푼 것 인계 — 오늘의 핵심

> 3회 프로그램에서 가장 중요한 산출물이 여기서 나온다.

## EXPLAIN

3회 동안 막힌 것들이 있다. 그중 일부는 더 해보면 풀리고, 일부는 **혼자서는 못 푼다.**

두 번째를 그냥 "안 됐다"로 두면 아무 데도 안 남는다. 성격을 갈라서 적어두면 그때부터 다룰 수 있는 문제가 된다.

성격은 넷이다.

| 성격 | 예 | 다룰 사람 |
|------|-----|----------|
| **권한** | 특정 시스템에 접근이 안 된다 | 조직 |
| **데이터** | 필요한 자료를 못 가져온다 | 조직 |
| **협조** | 다른 팀이 움직여야 한다 | 조직 |
| **학습** | 방법을 더 알면 될 것 같다 | 본인 |

앞의 셋은 개인이 더 잘한다고 넘어가지지 않는다. **어디가 막혔는지 정확히 적혀 있어야** 조직이 다룰 수 있다.

## EXECUTE

3회차 동안의 기록을 모아 목록을 만든다.

- Day 1 세 줄 3번
- Day 2 세 줄 3번 + "개인이 못 넘는 벽" 절
- 오늘 Block 1에서 나온 것

각 항목에 대해 묻는다.

```json
AskUserQuestion({
  "questions": [{
    "question": "<항목>은 어떤 성격인가요?",
    "header": "성격 가르기",
    "options": [
      {"label": "권한이 없어서", "description": "접근 자체가 막힘"},
      {"label": "데이터를 못 가져와서", "description": "자료 확보 문제"},
      {"label": "다른 팀이 움직여야 해서", "description": "협조 필요"},
      {"label": "방법을 더 알면 될 것 같아서", "description": "학습으로 해결 가능"}
    ],
    "multiSelect": true
  }]
})
```

항목마다 한 번씩. → 각 질문 후 ⛔ STOP.

**권한·데이터·협조로 분류된 것은 한 줄 더 받는다.**

```
그거 정확히 어디서 막히나요? 어떤 화면에서, 뭘 하려다가?
```

두루뭉술한 "권한이 없다"는 아무도 못 다룬다. **"○○ 화면에서 △△를 받으려는데 열람 권한이 없다"**가 다룰 수 있는 형태다.

## CHECK

정리한 인계 목록을 보여주고 확인한다.

```json
AskUserQuestion({
  "questions": [{
    "question": "인계 목록이 정리됐습니다. 이 중에 제일 크게 걸리는 건 뭐예요?",
    "header": "우선순위",
    "options": [
      {"label": "<권한/데이터 항목 A>", "description": "<설명>"},
      {"label": "<항목 B>", "description": "<설명>"},
      {"label": "<항목 C>", "description": "<설명>"},
      {"label": "다 비슷하다", "description": "우선순위 없음"}
    ],
    "multiSelect": false
  }]
})
```

선택지는 앞에서 나온 항목을 그대로 쓴다.

마무리로 이렇게 짚어준다:

> "이 목록이 오늘의 진짜 결과물일 수 있습니다. 3회 동안 도구를 배운 것보다, **우리 팀이 어디서 막히는지 구체적으로 아는 상태**가 된 게 더 큽니다."
