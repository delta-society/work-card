# Block 0: 이번 주에 실제로 썼나

## EXPLAIN

2회차 끝에 부탁했다 — 기준이 들어간 레시피를 실제 업무에 한 번 써보기.

썼든 안 썼든 오늘 진행에는 지장이 없다. **안 썼으면 왜 안 쓰게 됐는지가 오늘의 첫 재료다.**

도구가 안 좋아서 안 쓰는 경우는 드물다. 대개는 그 업무를 할 일이 이번 주에 없었거나, 열기 귀찮았거나, 한 번 어긋나서 신뢰가 떨어졌기 때문이다. 셋은 대응이 다르다.

## EXECUTE

Day 2 세 줄을 읽어준 뒤 물어본다.

```
저 레시피, 이번 주에 실제 업무 건으로 써보셨어요?
```

썼으면 어떤 건이었는지, 안 썼으면 왜 그랬는지 편하게 답한다.

- **2번**: "그럼 오늘 여기서 지난번 건으로 돌려봅니다. 실제 자료가 있으면 그걸로."
- **3번**: "그게 제일 중요한 신호입니다. 어디서 어긋났는지 오늘 그 자리를 고칩니다."
- **4번**: "마찰이 어디였는지 봅시다. 여는 것부터 줄일 수 있습니다."

어느 답이든 **Block 1에서 실제 업무 건으로 한 번 돌린다.**
