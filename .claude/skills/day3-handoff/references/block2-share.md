# Block 2: 남이 쓸 수 있게

## EXPLAIN

레시피의 값어치는 **다음 달의 나**와 **옆자리 동료**에게서 나온다.

지금은 만든 사람 머릿속에 있는 전제가 많다. 그 전제가 안 적혀 있으면 남이 열었을 때 안 돌아간다.

확인할 것은 셋이다.

- 이 레시피가 무엇을 하는 건지 **제목만 보고 알 수 있나**
- 시작할 때 뭐가 준비돼 있어야 하는지 적혀 있나
- 사람이 판단해야 하는 자리가 표시돼 있나

## EXECUTE

Claude에게 남의 눈으로 보게 시킨다.

```
이 스킬을 처음 보는 사람이 열었다고 치고, 뭐가 부족한지 알려줘
```

나온 지적 중 맞다고 생각하는 것만 고친다. **전부 반영할 필요 없다.**

```
<지적 중 맞는 것>을 반영해줘
```

여유가 있으면 하나 더 — 팀에 공유할 생각이 있으면 이렇게 물어본다.

```
이 스킬을 팀원한테 주려면 뭘 더 준비해야 해?
```
