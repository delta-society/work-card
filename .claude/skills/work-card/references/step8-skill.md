# Step 8: 스킬 생성 + 첫 실행

> 여기가 이 스킬의 목적지다. 카드는 중간 산출물일 뿐이다.

## 실행

카드 내용으로 `.claude/skills/<짧은이름>/SKILL.md`를 생성한다.

```markdown
---
name: <짧은이름>
description: <업무 이름>. <시작 신호>일 때 사용.
---

# <업무 이름>

## 재료
<재료 칸>

## 순서
<순서 칸을 단계로. 넘길 수 있는 단계는 그대로 실행하고,
 판단 지점에 오면 아래 규칙을 따른다>

## 사람이 정하는 것
<판단 지점> — **이 부분은 반드시 사용자에게 물어본다. 대신 정하지 않는다.**
판단 기준: <q5에서 나온 기준>

## 끝
<완료 조건>. 결과는 <수신자>에게 간다.
```

## 안내

만들고 나서 이렇게 알린다:

```
방금 말씀하신 걸로 스킬이 하나 생겼습니다.

  .claude/skills/<짧은이름>/SKILL.md

새 대화를 열고 /<짧은이름> 을 쳐보세요.
```

## 첫 실행 유도

```
지금 바로 한 번 돌려보시는 게 좋습니다.
첫 판은 대개 어긋나는데, 어긋나는 지점이 곧 고칠 지점입니다.

돌려보고 이상하면 그냥 말로 고치면 됩니다:
"아니 이 단계는 그전에 해야 돼" 처럼.
```

수정 요청이 오면 SKILL.md를 직접 고친다. **사용자가 파일을 열 필요 없다.**

## 완료 확인

세 개가 다 됐는지 확인한다:

- [ ] `work-cards/` 카드 파일
- [ ] `.claude/skills/<짧은이름>/SKILL.md`
- [ ] 사용자가 새 스킬 1회 실행

셋째가 안 됐으면 끝난 게 아니다. 돌려보게 한다.
