# 질문 4: 순서

## ASK

```
그다음엔 뭘 하세요? 순서대로 얘기해주세요.
```

열린 질문. 사용자가 말하는 대로 받아적는다.

⛔ STOP.

## PROBE

두세 단계에서 멈추면:

```
지난주에 이거 하셨죠? 그때 뭐부터 하셨어요?
```

**추상적으로 물으면 추상적으로 답한다.** 지난번 실제 사례 하나를 떠올리게 하는 편이 항상 빠르다.

## CAPTURE

`순서` 칸에 번호를 매겨 정리한다. 사용자 표현을 살린다 — "정리한다"를 "데이터 가공"으로 바꾸지 않는다.

**이 번호 목록이 다음 질문(q5)의 선택지가 된다.** 정확히 적어둔다.
