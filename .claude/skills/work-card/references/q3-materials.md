# 질문 3: 재료

## ASK

```
시작할 때 뭘 여세요? 어디서 가져오시는지도요.
```

여기는 AskUserQuestion 옵션이 안 맞는다 — 사람마다 도구가 너무 달라서 선택지를 주면 오히려 좁아진다. 열린 질문으로 묻는다.

⛔ STOP.

## PROBE

한 개만 말하면:

```
그거 열고 나서 또 뭐 보세요? 다른 창 안 켜세요?
```

대개 서너 개가 나온다. **이 개수가 곧 이 업무의 산만함**이고, 나중에 "이걸 한 군데로 모을 수 있나"의 근거가 된다.

## CAPTURE

`재료` 칸: 도구 이름 + 그 안에서 뭘 보는지.
