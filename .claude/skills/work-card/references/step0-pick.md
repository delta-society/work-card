# Step 0: 업무 고르기

## ASK

AskUserQuestion으로 묻는다. 옵션은 업무 이름이 아니라 **고르는 기준**이다 — 사용자가 자기 업무를 떠올리게 만드는 게 목적.

```json
AskUserQuestion({
  "questions": [{
    "question": "매주 하고 계신 일 중에 하나만 골라주세요. 어떤 쪽이 먼저 떠오르세요?",
    "header": "업무 고르기",
    "options": [
      {"label": "매번 비슷한 순서로 하는 일", "description": "순서가 거의 정해져 있는 것"},
      {"label": "시간은 걸리는데 어렵진 않은 일", "description": "손이 많이 가는 것"},
      {"label": "안 하면 누가 물어보러 오는 일", "description": "기다리는 사람이 있는 것"},
      {"label": "미루게 되는 일", "description": "시작이 잘 안 되는 것"}
    ],
    "multiSelect": false
  }]
})
```

선택을 받으면 이어서 묻는다: **"그게 구체적으로 어떤 일이에요?"**

⛔ 여기서 STOP.

## PROBE

여러 개를 말하면 **가장 최근에 한 것** 하나로 좁힌다:

```
그중에 제일 최근에 하신 게 뭐예요? 그걸로 해보죠.
```

기억이 살아 있는 쪽이 재료가 훨씬 많다.

## CAPTURE

- 업무 이름 (사용자가 부르는 말 그대로)
- 짧은이름: 파일/스킬 이름용. 사용자 표현에서 딴다. 한글 그대로도 된다.
