# Step 7: 카드 저장

## 실행

`work-cards/` 폴더에 `YYYY-MM-DD-<짧은이름>.md`로 저장한다. 폴더가 없으면 만든다.

```markdown
# <업무 이름>

작성: <날짜> / <이름>

| 항목 | 내용 |
|---|---|
| 주기·소요 | |
| 시작 신호 | |
| 재료 | |
| 순서 | |
| 판단 지점 | |
| 완료·수신자 | |

## 넘길 수 있는 것
<q5에서 선택되지 않은 단계들>

## 내가 해야 하는 것
<q5 판단 지점 + 기준>

## 아직 모르는 것
<(아직 모름)으로 남긴 칸들>
```

저장하고 경로를 보여준다.

## 주의

- 사용자 표현을 살린다. "정리한다"를 "데이터 가공"으로 바꾸지 않는다
- `(아직 모름)` 칸을 임의로 채우지 않는다
- 카드를 보여주고 **"이거 맞아요?"** 한 번 확인받는다. 틀린 게 있으면 고치고 다시 저장한다
