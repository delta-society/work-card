# Work Card — 반복 업무를 스킬로

이 스킬이 호출되면 아래 **진행 규칙**을 반드시 따른다.

---

## 진행 규칙 — 절대 위반 금지

### 1. 질문은 한 번에 하나씩

여섯 개 질문을 한 번에 쏟지 않는다. 하나 묻고, 답을 받고, 다음을 묻는다.

한꺼번에 물으면 사용자는 요약해서 답한다. 요약된 답에는 그 사람이 실제로 어떻게 일하는지가 빠진다. 이 스킬의 값어치는 그 빠지는 부분에 있다.

### 2. 대신 답하지 않는다

사용자가 "음..." 하고 막히더라도 예시를 던져 채우지 않는다. 기다린다.

한 번 막히면 이렇게만 되묻는다:

```
지난주에 이 일 하셨죠? 그때 뭐부터 하셨어요?
```

추상적으로 물으면 추상적으로 답한다. **지난번 실제 사례 하나**를 떠올리게 하는 편이 항상 빠르다.

### 3. 용어를 먼저 쓰지 않는다

`워크플로우`, `트리거`, `인풋/아웃풋`, `병목` 같은 말을 먼저 꺼내지 않는다. 사용자 언어로 묻고, 카드에 옮길 때 정리한다.

### 4. 모르는 칸은 비워둔다

여섯 칸을 다 못 채워도 카드를 만든다. `(아직 모름)`으로 남긴다. 빈 칸이 다음에 무엇을 알아내야 하는지를 알려준다. 억지로 채운 칸이 빈 칸보다 나쁘다.

---

## Step 1 — 업무 하나 고르기

먼저 이렇게 묻는다:

```
매주 하고 계신 일 중에서, 하나만 골라주세요.

- 매번 비슷한 순서로 하는 일
- 시간은 걸리는데 딱히 어렵진 않은 일
- 안 하면 누군가 물어보러 오는 일

이 중에 걸리는 게 있으면 그거면 됩니다.
```

사용자가 여러 개를 말하면 **가장 최근에 한 것** 하나로 좁힌다. 기억이 살아 있는 쪽이 재료가 많다.

## Step 2 — 여섯 가지 묻기

하나씩, 순서대로. 각 질문 뒤에 답을 받고 다음으로 간다.

| # | 묻는 말 | 카드에 들어갈 칸 |
|---|---|---|
| 1 | "이 일 얼마나 자주 하세요? 한 번에 몇 분쯤 걸려요?" | 주기·소요 |
| 2 | "뭘 보면 '아 이거 해야겠다' 하세요?" | 시작 신호 |
| 3 | "시작할 때 뭘 열어요? 어디서 가져오세요?" | 재료 |
| 4 | "그다음엔 뭘 하세요? 순서대로 얘기해주세요" | 순서 |
| 5 | "그중에 '이건 내가 정해야 한다' 싶은 데가 어디예요?" | 판단 지점 |
| 6 | "뭘 보면 끝났다고 하세요? 그리고 그거 누구한테 가요?" | 완료·수신자 |

**5번이 이 스킬의 핵심이다.** 판단 지점이 곧 그 사람이 대체 불가능한 지점이고, 나머지는 넘길 수 있는 부분이다. 5번 답이 얇으면 한 번 더 파고든다:

```
그때 뭘 보고 정하세요? 기준 같은 게 있나요?
```

## Step 3 — 카드 저장

`work-cards/` 폴더에 `YYYY-MM-DD-<짧은이름>.md`로 저장한다. 폴더가 없으면 만든다.

```markdown
# <업무 이름>

작성: <날짜> / <이름>

| 항목 | 내용 |
|---|---|
| 주기·소요 | |
| 시작 신호 | |
| 재료 | |
| 순서 | |
| 판단 지점 | |
| 완료·수신자 | |

## 넘길 수 있는 것
<순서 중 판단이 안 들어가는 단계들>

## 내가 해야 하는 것
<판단 지점>

## 아직 모르는 것
<비워둔 칸>
```

저장하고 경로를 보여준다.

## Step 4 — 카드에서 스킬 만들기

여기가 이 스킬의 목적지다.

카드 내용으로 `.claude/skills/<짧은이름>/SKILL.md`를 생성한다:

```markdown
---
name: <짧은이름>
description: <업무 이름>. <시작 신호>일 때 사용.
---

# <업무 이름>

## 재료
<재료 칸>

## 순서
<순서 칸을 단계로>

## 사람이 정하는 것
<판단 지점> — 이 부분은 사용자에게 물어본다. 대신 정하지 않는다.

## 끝
<완료 조건>. 결과는 <수신자>에게 간다.
```

만들고 나서 이렇게 알린다:

```
방금 말씀하신 걸로 스킬이 하나 생겼습니다.

  .claude/skills/<짧은이름>/SKILL.md

새 대화를 열고 /<짧은이름> 을 쳐보세요.
```

## Step 5 — 한 번 돌려보게 하기

```
지금 바로 한 번 돌려보시는 게 좋습니다.
첫 판은 대개 어긋나는데, 어긋나는 지점이 곧 고칠 지점입니다.

돌려보고 이상하면 그냥 말로 고치면 됩니다:
"아니 이 단계는 그전에 해야 돼" 처럼.
```

돌려본 뒤 수정 요청이 오면 SKILL.md를 직접 고친다. 사용자가 파일을 열 필요 없다.

---

## 완료 기준

- `work-cards/` 아래 카드 파일 1개
- `.claude/skills/<짧은이름>/SKILL.md` 1개
- 사용자가 새 스킬을 최소 1회 실행

세 개가 다 되면 끝이다. 카드만 만들고 끝내지 않는다 — 돌아가는 걸 봐야 자기 것이 된다.
