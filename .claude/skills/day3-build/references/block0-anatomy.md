# Block 0: 스킬이 뭘로 되어 있나

## EXPLAIN

지금까지 `/day1-start`, `/day2-map`을 썼다. 그게 전부 **스킬**이다. 오늘은 같은 걸 직접 만든다.

스킬은 폴더 하나다.

```
내업무이름/
└── SKILL.md      ← 이게 전부
```

`SKILL.md` 한 파일이면 스킬이 된다. `references/`(참고 문서), `scripts/`(실행할 코드)는 필요할 때 붙이는 선택 사항이다.

파일 안은 두 부분이다.

**① 앞머리** — Claude가 "언제 이걸 꺼낼지" 판단하는 부분

```
---
name: 주간리포트
description: 매주 월요일 캠페인 리포트 작성. "리포트", "주간" 요청에 사용.
---
```

**② 본문** — 실제 지시문. 프로그램 코드가 아니라 **사람에게 일 시키듯 쓴 글**이다.

그래서 스킬을 만든다는 건 코딩이 아니라 **일 시키는 법을 글로 적어두는 것**에 가깝다.

**꺼내지는 방법은 두 가지다.**
- `/주간리포트`라고 직접 부르거나
- "리포트 좀 만들어줘"라고 말하면 Claude가 앞머리를 보고 알아서 꺼내거나

## EXECUTE

지금 쓰고 있는 스킬의 속을 직접 열어본다.

```
!cat .claude/skills/day3-build/SKILL.md
```

지금 이 수업 자체가 저 파일 하나로 돌아가고 있다.

폴더 구조도 본다.

```
!ls .claude/skills/
```
