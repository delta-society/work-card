# Block 3: 말로 고치기

## EXPLAIN

스킬을 고칠 때 파일을 직접 열 필요 없다. **Claude에게 말로 하면 된다.**

```
아니 이 단계는 그전에 해야 돼
```
```
여기서는 물어보지 말고 그냥 진행해
```
```
이 부분에서 한 번 확인받고 가자
```

이렇게 말하면 Claude가 SKILL.md를 고친다.

여기가 이 프로그램에서 제일 중요한 대목이다. **한 번에 완벽하게 만드는 게 아니라, 쓰면서 고쳐 나간다.** 쓸수록 내 일에 맞아 들어간다.

## EXECUTE

방금 이상했던 부분을 말로 고친다.

Block 2에서 고른 항목을 그대로 가져와 문장으로 만들어준다.

- "물어봐야 할 데서 안 물어봤다" → `<그 단계>에서는 나한테 물어보고 진행하게 해줘`
- "안 물어도 될 걸 물었다" → `<그 단계>는 물어보지 말고 그냥 진행해`
- "순서가 틀렸다" → `<A>를 <B>보다 먼저 하게 바꿔줘`

고친 뒤 **한 번 더 돌려본다.**

```
/<짧은이름>
```

2·3번이면 한 번 더 고친다. 횟수 제한은 없다 — **고치는 경험 자체가 오늘의 학습이다.**

1번이면 이렇게 짚어준다:

> "지금 하신 게 앞으로 계속 하실 일입니다. 쓰다가 걸리면 말로 고치고, 또 쓰고. 그렇게 내 일에 맞아 들어갑니다."
