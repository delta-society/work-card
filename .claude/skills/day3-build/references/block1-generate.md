# Block 1: 내 카드를 스킬로

> 오늘의 목적지다.

## EXPLAIN

2회차에 만든 카드를 그대로 스킬로 옮긴다.

중요한 건 **판단 지점을 어떻게 처리하느냐**다.

- `넘길 수 있는 것` → 스킬이 알아서 실행한다
- `내가 해야 하는 것` → **스킬이 멈추고 나에게 물어본다**

두 번째가 핵심이다. 이 구분이 없으면 AI가 내가 정해야 할 것까지 혼자 정해버린다. 그럴듯하지만 내 판단이 아닌 결과가 나온다.

## EXECUTE

카드를 읽고 `.claude/skills/<짧은이름>/SKILL.md`를 생성한다.

```markdown
---
name: <짧은이름>
description: <업무 이름>. <시작 신호>일 때 사용.
---

# <업무 이름>

## 재료
<카드의 재료 칸>

## 순서
<카드의 순서 칸을 단계로>

넘길 수 있는 단계는 그대로 실행한다.
판단 지점에 오면 아래 규칙을 따른다.

## 사람이 정하는 것
<판단 지점>

**이 부분은 반드시 사용자에게 물어본다. 대신 정하지 않는다.**
물을 때는 AskUserQuestion으로 선택지를 만들어 묻는다.

판단 기준: <2회차에서 나온 기준>

## 끝
<완료 조건>. 결과는 <수신자>에게 간다.
```

만든 뒤 파일 전문을 보여주고, 어느 부분이 카드의 어느 칸에서 왔는지 짚어준다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "스킬 파일이 만들어졌습니다. 읽어보시니 어떠세요?",
    "header": "생성 확인",
    "options": [
      {"label": "생각보다 단순하네요", "description": "글 한 장이 전부"},
      {"label": "판단 지점 부분이 마음에 듭니다", "description": "물어보게 되어 있음"},
      {"label": "빠진 게 있는 것 같아요", "description": "어디인지 알려주세요"},
      {"label": "이게 정말 돌아가나요?", "description": "다음 블록에서 확인"}
    ],
    "multiSelect": false
  }]
})
```

3번이면 바로 고쳐서 다시 보여준다. 4번이면 이렇게 답한다:

> "지금 바로 돌려봅니다. 첫 판은 대개 어긋나는데, 그게 정상입니다."
