# Block 2: 돌려보기 — 첫 판은 어긋난다

## EXPLAIN

만들었으면 돌려봐야 한다. **만들고 끝내면 자기 것이 안 된다.**

첫 판은 대개 어긋난다. 순서가 틀렸거나, 물어봐야 할 데서 안 물어보거나, 안 물어도 될 걸 묻는다.

**그게 실패가 아니라 오늘의 두 번째 재료다.** 어긋나는 지점이 곧 고칠 지점이다.

## EXECUTE

**새 대화를 연다.** 지금 창에서 돌리면 이 수업 맥락이 섞인다.

터미널에서:

```
claude
```

그리고 방금 만든 스킬을 부른다.

```
/<짧은이름>
```

끝까지 따라가 본다. 중간에 이상해도 멈추지 말고 끝까지 간다 — 어디까지 맞고 어디서부터 틀리는지 봐야 한다.

**볼 것 세 가지**
1. 순서대로 가는가
2. 판단 지점에서 실제로 나에게 물어보는가
3. 안 물어도 될 걸 묻지는 않는가
