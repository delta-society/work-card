# Block 4: 남은 것 정리

## EXPLAIN

3회가 끝났다. 손에 남은 것을 확인하고, **혼자 못 푼 것**을 적어둔다.

못 푼 것을 적는 게 왜 중요한가. 두 종류로 갈리기 때문이다.

- **더 해보면 풀리는 것** — 방법을 아직 모를 뿐
- **혼자서는 못 푸는 것** — 권한, 데이터 접근, 다른 팀 협조가 필요한 것

두 번째는 개인이 더 잘한다고 넘어가지지 않는다. 그건 따로 다뤄야 할 문제이고, **어디가 막혔는지 정확히 적혀 있어야** 다룰 수 있다.

## EXECUTE

카드 파일 맨 아래에 아래를 덧붙인다.

```markdown
## 3회차 결과

- 만든 스킬: `.claude/skills/<짧은이름>/SKILL.md`
- 돌려본 결과: <Block 2 응답>
- 고친 내용: <Block 3에서 고친 것>

## 혼자 못 푼 것
<아래 CHECK에서 받은 답>
```

## CHECK

먼저 3회 전체를 짚어준다.

```
3회 동안 이렇게 왔습니다.

  1회차 — 켜고, 감 잡고, 업무 하나 골랐다
  2회차 — 순서를 펼치고, 내가 판단할 지점을 찾았다
  3회차 — 그걸 돌아가는 스킬로 만들고, 돌려보고, 고쳤다

지금 `/<짧은이름>` 하나가 남았습니다.
```

그다음 묻는다.

```json
AskUserQuestion({
  "questions": [{
    "question": "해보면서 '이건 나 혼자서는 안 되겠다' 싶었던 게 있나요?",

    "options": [
      {"label": "권한이 없어서 막혔다", "description": "접근 권한 문제"},

      {"label": "다른 팀이 움직여야 한다", "description": "협조 필요"},
```

1~3번을 골랐으면:

> "그건 개인이 더 잘해서 넘을 수 있는 벽이 아닙니다. 적어두신 것 자체가 결과입니다 — 어디가 막혔는지 정확히 아는 상태가 됐으니까요."

4번만 골랐으면:

> "그럼 계속 쓰시면서 늘어납니다. 걸릴 때마다 Claude한테 물어보시면 됩니다."

마지막 안내:

```
카드에 다 적어뒀습니다.

내일 아침에 /<짧은이름> 한 번 열어보세요.
하루 지나서도 돌아가면 진짜 자기 것이 된 겁니다.
```
