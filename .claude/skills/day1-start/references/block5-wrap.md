# Block 5: 세 줄로 남기기

> 자료 26~27장 대응. **이 세 줄이 수요일 세션 설계의 전부다.**

## EXPLAIN

잘 쓸 필요 없다. 솔직하게만 써주면 된다.

```
1. 내가 매주 잃고 있던 시간은     — 한 줄로. 오늘 고른 그 업무.
2. 오늘 실제로 시도한 것은        — 한 줄로. 결과가 좋았는지는 상관없다.
3. 아직 안 풀린 것은             — 한 줄로. 이 줄이 가장 중요하다.
```

## EXECUTE

세 줄을 받아 `work-cards/YYYY-MM-DD-<이름>.md`로 저장한다. 폴더가 없으면 만든다.

```markdown
# <업무 이름> — Day 1

작성: <날짜> / <이름>

## 세 줄
1. 매주 잃고 있던 시간:
2. 오늘 시도한 것:
3. 아직 안 풀린 것:

## 오늘 만든 것
- CLAUDE.md: <있음/없음>
- Skill: <이름 또는 "미완 — 어디서 멈췄는지">

## 인수인계서에서 어려웠던 줄
<Block 3 CHECK 응답>

## 레시피에서 막힌 지점
<Block 4 CHECK 응답 + 답 못 한 되묻기 질문들>
```

저장하고 경로를 보여준다.

### 예측 회수

시작할 때 걸어둔 두 가지를 같이 확인한다.

```
예측 ① 오늘 이 방의 절반은 AI가 준 그럴듯한 오답을 최소 한 번은 믿고 넘어간다
예측 ② "뭐가 제일 막히세요?"라고 물으면 대부분 "그냥 다 바쁘다"로 답하게 된다
```

맞았는지 사용자에게 묻고, 맞았으면 이렇게 짚는다:

> "못해서 생기는 일이 아닙니다. AI를 쓰기 시작할 때 누구에게나 똑같이 나타나는 구간입니다."

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "오늘 걸어둔 예측 두 가지, 맞았나요?",
    "header": "예측 회수",
    "options": [
      {"label": "둘 다 맞았다", "description": "그럴듯한 오답 + 다 바쁘다"},
      {"label": "①만 맞았다", "description": "그럴듯한 오답을 믿었다"},
      {"label": "②만 맞았다", "description": "막히는 걸 말하기 어려웠다"},
      {"label": "둘 다 아니었다", "description": "잘 지나가셨습니다"}

    "multiSelect": false
  }]
})
```

마무리 안내:

```

[이번 주 사이에]

  "제출"이 아니라 "흔적", 한 줄이면 충분합니다.
· 내일 아침에 한 번 — 이게 가장 중요합니다.
  이틀이 지나면 대부분 다시 안 엽니다.

[남은 두 번]

수요일 내용은 오늘 나온 세 줄로 정합니다. 미리 짜여 있지 않습니다.
```
