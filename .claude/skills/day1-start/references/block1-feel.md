# Block 1: 감 잡기 — 추측 vs 질문

## EXPLAIN

AI에게 일을 시킬 때 결과가 갈리는 지점은 **AI가 추측했느냐, 물어봤느냐**다.

모호하게 시키면 AI는 혼자 알아서 짐작하고 그럴듯한 답을 내놓는다. 그럴듯하지만 내가 원한 게 아니다.

한 마디를 붙이면 달라진다. AI가 추측을 멈추고 되묻기 시작한다.

## EXECUTE

두 번 시켜보고 차이를 직접 본다.

**1. 일부러 모호하게**

```
우리 팀 업무를 개선해줘
```

Claude가 혼자 짐작해서 답을 내놓을 것이다. 그 답을 잘 봐둔다.

**2. 같은 요청에 한 마디만 붙여서**

```
우리 팀 업무를 개선해줘. 모호한 부분은 AskUserQuestion으로 질문해서 명확하게 만들어
```

이번엔 Claude가 선택지를 주면서 되묻는다.

두 결과가 어떻게 다른지 본인 눈으로 확인한다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "두 번 시켜보니 뭐가 제일 달랐나요?",
    "header": "체험 확인",
    "options": [
      {"label": "질문을 하기 시작했다", "description": "추측 대신 되물음"},
      {"label": "답이 훨씬 내 상황에 맞았다", "description": "결과 정확도가 달라짐"},
      {"label": "느리지만 정확해졌다", "description": "속도와 정확도의 교환"},
      {"label": "별 차이 없었다", "description": "그럴 수도 있음"}
    ],
    "multiSelect": false
  }]
})
```

정답은 없다. 피드백은 이렇게 준다:

> "이게 오늘 제일 중요한 한 마디입니다. AI가 못하는 게 아니라, 내 상황을 모르는 겁니다. 물어보게 만들면 됩니다."

"별 차이 없었다"를 골랐으면 요청이 이미 충분히 구체적이었을 가능성이 크다. 더 모호한 요청으로 한 번 더 해보게 한다.
