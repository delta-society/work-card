# Block 2: 기초 — 명령어를 안 외워도 되는 이유

## EXPLAIN

터미널 명령어를 외워야 할 것 같지만, 그럴 필요 없다. Claude에게 말로 시키면 Claude가 대신 친다.

다만 뒤에서 뭐가 벌어지는지 알면 더 똑똑하게 시킬 수 있다.

| 명령어 | 뜻 | 비유 |
|--------|------|------|
| `pwd` | 지금 어느 폴더인가 | 주소창 보기 |
| `ls` | 여기 뭐가 있나 | 폴더 열어보기 |
| `cd` | 폴더 이동 | 더블클릭 |

그리고 하나 더 — 명령어 앞에 `!`를 붙이면 **Claude를 거치지 않고 내가 직접** 실행한다.

## EXECUTE

세 가지를 순서대로 해본다.

**1. Claude에게 시키기**

```
지금 내가 어느 폴더에 있는지 알려줘
```

Claude가 `pwd`를 대신 실행해서 알려줄 것이다.

**2. 하나 더**

```
이 폴더에 뭐가 있는지 보여줘
```

**3. 이번엔 내가 직접**

```
!ls
```

`!`를 붙였더니 Claude가 아무 말 없이 결과만 나온다. "Claude한테 시키지 말고 내가 직접 할게"라는 뜻이다.
