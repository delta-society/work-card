# Block 3: 내 업무 하나 고르기

> 여기서부터 오늘의 실질 산출물이 나온다.
> 오늘은 **고르고 겉만** 적는다. 속을 파는 건 2회차다.

## EXPLAIN

지금부터는 배우는 게 아니라 **내 일**을 다룬다.

매주 반복하는 업무 하나를 골라서, 그게 어떤 일인지 AI가 읽을 수 있는 형태로 남긴다. 오늘은 겉면만 — 얼마나 자주 하고, 뭘 보면 시작하고, 뭘 여는지.

이 카드가 2회차에서 채워지고, 3회차에서 스킬이 된다.

## EXECUTE

**질문 하나에 턴 하나다. 몰아서 묻지 않는다.**

### 1단계 — 업무 고르기

```json
AskUserQuestion({
  "questions": [{
    "question": "매주 하시는 일 중에 하나만 골라주세요. 어떤 쪽이 먼저 떠오르세요?",
    "header": "업무 고르기",
    "options": [
      {"label": "매번 비슷한 순서로 하는 일", "description": "순서가 거의 정해진 것"},
      {"label": "시간은 걸리는데 어렵진 않은 일", "description": "손이 많이 가는 것"},
      {"label": "안 하면 누가 물어보러 오는 일", "description": "기다리는 사람이 있는 것"},
      {"label": "자꾸 미루게 되는 일", "description": "시작이 잘 안 되는 것"}
    ],
    "multiSelect": false
  }]
})
```

이어서 묻는다: **"그게 구체적으로 어떤 일이에요?"** → ⛔ STOP

여러 개를 말하면 **가장 최근에 한 것**으로 좁힌다. 기억이 살아 있는 쪽이 재료가 많다.

### 2단계 — 주기와 소요

```json
AskUserQuestion({
  "questions": [{
    "question": "이 일 얼마나 자주 하세요?",
    "header": "주기",
    "options": [
      {"label": "주 1회", "description": "정해진 요일에"},
      {"label": "주 2~3회", "description": "여러 번"},
      {"label": "매일", "description": "거의 날마다"},
      {"label": "비정기", "description": "생길 때마다"}
    ],
    "multiSelect": false
  }]
})
```

이어서: **"한 번에 몇 분쯤 걸려요? 대충이면 됩니다."** → ⛔ STOP

"글쎄요"라고 하면 한 번만 되묻는다: *"지난번에 하실 때 시작해서 끝까지 커피 몇 잔 드셨어요?"* 정확한 숫자가 목적이 아니라 **"생각보다 오래 걸리네"를 본인이 느끼는 것**이 목적이다.

### 3단계 — 시작 신호

```json
AskUserQuestion({
  "questions": [{
    "question": "뭘 보면 '아 이거 해야겠다' 하세요?",
    "header": "시작 신호",
    "options": [
      {"label": "요일·시각이 되면", "description": "달력이 신호"},
      {"label": "누가 요청하면", "description": "사람이 신호"},
      {"label": "뭔가 쌓이면", "description": "양이 신호"},
      {"label": "그냥 내가 챙겨야 함", "description": "신호 없음 — 기억에 의존"}
    ],
    "multiSelect": false
  }]
})
```

4번을 고르면 한 번 더: *"그럼 깜빡한 적도 있으세요?"* → **깜빡한 경험이 있으면 그 자체가 자동화 1순위 신호다.** 카드에 표시해둔다.

### 4단계 — 재료

```
시작할 때 뭘 여세요? 어디서 가져오시는지도요.
```

열린 질문으로 묻는다(사람마다 도구가 달라 선택지를 주면 오히려 좁아진다). → ⛔ STOP

한 개만 말하면 한 번 되묻는다: *"그거 열고 나서 또 뭐 보세요? 다른 창 안 켜세요?"* 대개 서너 개가 나오고, **이 개수가 곧 이 업무의 산만함**이다.

### 5단계 — 카드 저장

`work-cards/YYYY-MM-DD-<짧은이름>.md`로 저장한다. 폴더가 없으면 만든다.

```markdown
# <업무 이름>

작성: <날짜> / <이름>

| 항목 | 내용 |
|---|---|
| 주기·소요 | |
| 시작 신호 | |
| 재료 | |
| 순서 | (2회차) |
| 판단 지점 | (2회차) |
| 완료·수신자 | (2회차) |
```

**아래 세 칸은 비워둔 채로 저장한다.** 오늘 채우지 않는다. 저장하고 경로를 보여준다.

사용자 표현을 살린다 — "정리한다"를 "데이터 가공"으로 바꾸지 않는다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "카드가 만들어졌습니다. 적힌 내용이 실제와 맞나요?",
    "header": "카드 확인",
    "options": [
      {"label": "맞아요", "description": "이대로 두기"},
      {"label": "고칠 데가 있어요", "description": "어디인지 알려주세요"},
      {"label": "다시 보니 다른 업무가 낫겠어요", "description": "처음부터 다시"}
    ],
    "multiSelect": false
  }]
})
```

마무리 안내:

```
오늘은 여기까지입니다.

카드의 아래 세 칸(순서 / 판단 지점 / 완료)은 비어 있습니다.
2회차에서 채웁니다.

[다음까지 해보실 것]
오늘 만든 환경에서 아무거나 두 번만 시켜보세요.
잘 된 것도 안 된 것도 채널에 한 줄 + 화면 캡처로 남겨주세요.
내일 아침에 한 번 열어보시길 권합니다. 하루 지나면 손이 굳습니다.
```
