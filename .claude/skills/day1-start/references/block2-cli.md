# Block 2: 명령어를 외우지 않아도 되는 이유

> 자료 23장 대응.

## EXPLAIN

터미널 명령어를 외워야 할 것 같지만 그럴 필요 없다. Claude에게 말로 시키면 Claude가 대신 친다.

참고로 자주 나오는 다섯 개 — **외우는 용도가 아니라 화면에서 길을 잃었을 때 돌아오는 용도**다.

| 명령어 | 익숙한 것으로 바꾸면 |
|--------|---------------------|
| `cd 폴더명` | 폴더 더블클릭해서 들어가기 |
| `ls` | 폴더 열어서 뭐 있나 보기 |
| `pwd` | 주소창 확인 |
| `cat 파일명` | 메모장으로 파일 열기 |
| `open 파일명` | 더블클릭 (Mac) |

나머지는 전부 말로 시키면 된다.

## EXECUTE

**말로 시켜본다**

```
지금 내가 어느 폴더에 있는지 알려줘
```

AI가 알아서 `pwd`를 실행한다.

```
이 폴더가 git으로 관리되고 있는지 확인해줘
```

AI가 알아서 `git status`를 실행한다.

**직접 치고 싶을 때**

```
!ls
```

`!`는 "Claude 말고 내가 직접 친다"는 뜻이다.
