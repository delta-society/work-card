# Block 1: 추측과 질문의 차이

> 자료 22장 대응. 외우지 말고 느끼기만 한다.

## EXPLAIN

같은 요청을 두 번 한다. 한 번은 그냥, 한 번은 한 마디를 붙여서.

AI가 **추측하느냐 되묻느냐**에서 결과가 갈린다. 성능 차이가 아니라 주어진 맥락의 차이다.

## EXECUTE

**1차 — 일부러 모호하게**

```
우리 팀 업무를 개선해줘
```

AI가 알아서 추측한다. 그럴듯하지만 우리 팀 얘기가 아니다.

**2차 — 되묻게 시키기**

```
우리 팀 업무를 개선해줘. 모호한 부분은 나한테 질문해서 명확하게 만들어
```

AI가 되묻기 시작한다. **그 질문들이 곧 내 업무의 핵심 변수다.**

**하나 더**

모르는 게 나오면 그냥 물어본다.

```
MCP가 뭐야?
```

기능을 외울 필요가 없는 이유다.
