# Block 4: 반복 업무를 레시피로

> 자료 25장 대응. **오늘 완성 못 해도 된다** — 어디서 막히는지 확인하는 것까지가 오늘 몫이다.

## EXPLAIN

`CLAUDE.md`가 항상 읽히는 규칙서라면, **Skill은 필요할 때만 꺼내 읽히는 레시피**다.

한 번 만들어 두면
- 같은 업무를 다음 달에 다시 할 때 설명을 처음부터 다시 하지 않는다
- 그 품질이 고정된다
- 다른 사람도 그대로 쓸 수 있다

### 고르는 질문

> "매주 시간을 쓰고 있거나, 계속 시작을 못 하고 있는 일 하나는?"

딱 하나만. 크지 않아도 된다. **오히려 작을수록 오늘 끝난다.**

떠오르지 않으면 바꿔서 묻는다:

> "되고 싶은 모습이 있다면, 그걸 위해 매일 해야 하는 일 하나는?"

## EXECUTE

세 단계다.

**1단계 — 말로 설명한다**

그 일을 어떻게 하는지 AI에게 그냥 말로 설명한다. 순서, 자료, 판단 기준.

**2단계 — 되묻게 한다**

```
내 설명에서 빠진 게 뭐야?
```

여기서 나오는 질문이 **그 업무의 암묵지**다. 답하면서 자기도 몰랐던 걸 알게 된다.

**3단계 — 레시피로 고정한다**

```
지금까지 내용을 Skill로 만들어줘
```

`.claude/skills/<이름>/SKILL.md`가 생긴다. 새 대화에서 `/<이름>`을 치면 그 일이 돌아간다.

### 진행 규칙

- **1단계에서 사용자가 두세 마디로 끝내도 재촉하지 않는다.** 2단계 되묻기가 그 역할을 한다.
- 2단계에서 나온 질문 중 사용자가 **답하지 못한 것**을 따로 적어둔다 — 그게 오늘의 진짜 수확이다.
- 3단계까지 못 가도 된다. 1·2단계에서 멈추면 거기까지가 오늘 결과다.
- 만들어진 Skill을 한 번 돌려볼 시간이 있으면 돌려본다. 없으면 넘어간다.

## CHECK

```json
AskUserQuestion({
  "questions": [{
    "question": "어디까지 가셨나요?",
    "header": "레시피 확인",
    "options": [
      {"label": "Skill까지 만들었다", "description": "3단계 완료"},
      {"label": "되묻기에서 답이 막혔다", "description": "2단계에서 멈춤"},
      {"label": "설명하다 보니 순서가 애매했다", "description": "1단계에서 걸림"},
      {"label": "어떤 일을 고를지가 어려웠다", "description": "시작에서 걸림"}
    ],
    "multiSelect": false
  }]
})
```

**2·3·4번이 1번보다 좋은 답일 수 있다.** 이렇게 말해준다:

> "막힌 지점이 오늘의 수확입니다. 수요일 세션은 미리 짜여 있지 않고, 오늘 나온 이 지점들로 정합니다."

1번이면:

> "새 대화를 열고 `/<이름>` 한 번 쳐보세요. 첫 판은 대개 어긋나는데, 어긋나는 지점이 곧 고칠 지점입니다."
